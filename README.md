# 🔍 Мониторинг конкурентов - AI Ассистент

AI-инструмент для анализа конкурентов в нише HR / карьера / EdTech (текст, сайты, визуал).

## 🚀 Что это дает бизнесу

- Быстрая оценка конкурентов в HR / EdTech нише
- Выявление сильных и слабых сторон продуктов
- Поиск точек автоматизации (рекрутинг, обучение, UX)
- Сравнение сервисов по единым метрикам (Design / UX / HR relevance)
- Экспорт результатов анализа в PDF-отчёт для передачи заказчику, руководителю или включения в портфолио

**Подходит для:**

- HR-аналитиков
- продуктовых менеджеров
- EdTech-команд

Инструмент для анализа конкурентной среды: текст, изображения и страницы сайтов (ниша HR / карьера / EdTech).

## 🧠 Как работает система

1. **Получение данных** — текст, изображение или URL сайта.
2. **Предобработка** — для сайтов: загрузка в браузере, скриншот, извлечение видимого текста и структуры страницы.
3. **Анализ через LLM** — запросы к модели через ProxyAPI (OpenAI-compatible).
4. **Единая модель** — ответ приводится к схеме `CompetitorAnalysis` (метрики и текстовые блоки).
5. **Вывод** — результаты в веб-интерфейсе и при необходимости в desktop-оболочке.

Результат — структурированная аналитика, пригодная для принятия решений.

Может использоваться как основа для:

## 📋 Описание

Система позволяет:

- **Анализировать текст конкурентов** — структурированная аналитика: сильные/слабые стороны, УТП, рекомендации, резюме и **единая HR/EdTech-оценка** (баллы и поля ниже).
- **Анализировать изображения** — баннеры, скриншоты, визуальные материалы: описание, маркетинговые инсайты, оценка визуального стиля (0–10), рекомендации.
- **Парсить сайты через Selenium + Chrome** — загрузка страницы, **скриншот**, **видимый текст**, затем **анализ через LLM** (тот же конкурентный отчёт, что и для текста).
- **Хранить историю** — последние запросы сохраняются для быстрого доступа.
- **Экспортировать результаты анализа в PDF** — отчёт включает исходные данные (для текстового режима), оценки, сильные/слабые стороны, рекомендации и резюме.

### Единая модель оценки (текст и результат парсинга сайта)

Ответ `CompetitorAnalysis` включает:

- `design_score`, `ux_score`, `hr_relevance_score` (0–10)
- `target_audience` — целевая аудитория (работодатели, кандидаты, EdTech и т.д.)
- `automation_potential` — идеи автоматизации HR/рекрутинга
- плюс списки сильных/слабых сторон, УТП, рекомендаций и `summary`

## 🚀 Быстрый старт

### 1. Клонирование и установка зависимостей

```bash
# Перейдите в каталог проекта
cd competitor-monitor

# Создайте виртуальное окружение
python -m venv venv

# Активируйте окружение
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate

# Установите зависимости
pip install -r requirements.txt
```

### 2. Настройка переменных окружения

Скопируйте `.env.example` в `.env` в корне проекта и задайте ключ доступа к ProxyAPI (см. комментарии в `.env.example`).

```bash
# Windows:
copy .env.example .env

# Linux / macOS:
cp .env.example .env
```

**Экспорт PDF (кириллица).** ReportLab не встраивает стандартные шрифты с кириллицей. Для корректного русского текста в отчёте положите в каталог `backend/assets/fonts/` два файла **TTF** с поддержкой кириллицы (например скопируйте с Windows `%WINDIR%\Fonts\arial.ttf` и `arialbd.ttf`), либо используйте установленные системные шрифты Windows — тогда по умолчанию подставляются `arial.ttf` и `arialbd.ttf` из `%WINDIR%\Fonts`. Сами файлы системных шрифтов в репозиторий не добавляйте; в Git остаётся только пустая заготовка `backend/assets/fonts/.gitkeep`.

### 3. Запуск приложения

Рекомендуемый способ — скрипт из корня проекта (как при ручном запуске, так и при автозапуске из desktop):

```bash
python run.py
```

Альтернатива — напрямую через Uvicorn:

```bash
python -m uvicorn backend.main:app --reload --host 0.0.0.0 --port 8000
```

Приложение будет доступно по адресу: http://localhost:8000

## 💻 Desktop

Оболочка на **PyQt6** с **QWebEngineView** открывает тот же веб-интерфейс, что и браузер.

```bash
# Из корня проекта (рядом с run.py)
python desktop/main.py
```

Поведение при старте:

1. Запрос **`GET /health`** к API (порт по умолчанию совпадает с настройками backend).
2. Если сервер уже запущен — сразу открывается веб UI.
3. Если недоступен — desktop поднимает **`python run.py`** из корня проекта (subprocess, рабочий каталог — каталог с `run.py`), ждёт готовность по `/health`, затем открывает окно.
4. При закрытии desktop процесс backend, **запущенный самим desktop**, корректно завершается.
5. Лог stdout/stderr автозапуска при необходимости смотрите в `desktop/backend_startup.log`.
6. В desktop-режиме поддерживается скачивание PDF через системный диалог сохранения файла (обработка загрузок в Qt WebEngine).
7. Добавлена кнопка **«Выход»**, которая корректно закрывает приложение и завершает backend-процесс, если он был запущен desktop-оболочкой.

Подробности по сборке exe — в `desktop/README.md`.

## 🔧 Функциональность

### Анализ текста (`/analyze_text`)

- Принимает текст конкурента (минимум 10 символов).
- Показывает сильные/слабые стороны, УТП, рекомендации, резюме и **HR/EdTech-метрики**: `design_score`, `ux_score`, `hr_relevance_score`, `target_audience`, `automation_potential`.

### Анализ изображений (`/analyze_image`)

- Форматы: PNG, JPG, GIF, WEBP.
- Позволяет получить описание, маркетинговые инсайты, оценку визуального стиля (0–10), рекомендации.

### Парсинг сайтов (`/parse_demo`)

- **Selenium + Chrome** (видимый браузер, не headless по умолчанию): переход по URL, устойчивость к таймаутам загрузки.
- Снимается **скриншот** страницы, извлекается **видимый текст** (и базовые поля: title, h1, первый абзац где удаётся).
- Контент передаётся в **LLM**; в интерфейсе — структурированный анализ в формате **`CompetitorAnalysis`** (те же баллы и HR-поля, что и для текста).

### История (`/history`)

- Хранит последние запросы (лимит настраивается в backend).
- Сохраняет тип запроса, краткое описание, время.

### Экспорт PDF (`/export_pdf`)

- Формирует PDF-отчёт по текущему результату анализа.
- Поддерживает текстовый анализ, анализ сайта и анализ изображения.
- Использует русскоязычный шрифт с поддержкой кириллицы (TTF в `backend/assets/fonts/` или системные шрифты Windows).
- В desktop-версии открывает стандартный диалог сохранения файла.

## 🛠️ Технологии

- **Backend:** FastAPI, Python 3.9+
- **AI:** ProxyAPI (OpenAI-compatible API), модели задаются в конфигурации
- **Парсинг страниц:** Selenium, Google Chrome, webdriver-manager
- **Frontend:** HTML, CSS, JavaScript (без фреймворка)
- **Desktop:** PyQt6, QWebEngineView (встраивание веб UI)
- **Валидация и схемы API:** Pydantic v2
- **PDF-экспорт:** ReportLab

Клиент `openai` для HTTPS может использовать внутренние HTTP-библиотеки; **разбор HTML для демо-парсинга** выполняется через браузер, а не через BeautifulSoup.
